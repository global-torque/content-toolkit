# Security Policy

## Supported versions

| Version                        | Security fixes                |
| ------------------------------ | ----------------------------- |
| Latest `0.2.x`                 | Supported                     |
| Older versions and prereleases | Upgrade to the latest release |

Report security issues for the public package through:

- GitHub: https://github.com/global-torque/content-toolkit/security/advisories/new

Do not include secrets, private content, customer data, or unpublished
vulnerability details in public issues.

Maintainers target an acknowledgement within three business days and an initial
triage response within seven business days. Remediation and disclosure timing
depend on severity and whether an affected immutable artifact exists. A report
is not considered public until maintainers and the reporter coordinate
disclosure through the private advisory.
